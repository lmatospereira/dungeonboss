# Masmorra do Rei Ogro

RPG de masmorra em 3D com combate por turnos, que roda no navegador e também vira app Android. Tem 8 heróis, 4 masmorras com chefes, evolução de nível e Invasão (PvP assíncrono).

Guia completo em português: [LEIAME.md](LEIAME.md).

```bash
npm install
npm run build          # gera www/ (site e app) e dist/artifact.html
npx http-server www    # abre em http://localhost:8080
```
